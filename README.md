# Job Portal Frontend Project

## Description
A responsive job portal frontend built using HTML, CSS, and JavaScript.
Users can view job listings and apply through a form with client-side validation.

## Features
- Job listings UI
- Apply button with page validation
- Success message on submit
- Responsive design using Flexbox

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the repository
2. Open `index.html` in a browser
